# Syscore

Готовый адаптивный сайт-визитка центра кибербезопасности. Светлая стилистика основана на предоставленном логотипе: белый, графитовый и мятный цвета.

## Что входит

- Одностраничный сайт с разделами: главная, направления, о проекте, образование, контакты.
- Выезжающее меню с клавиатурной навигацией, закрытием по Escape и возвратом фокуса.
- Шесть раскрывающихся описаний направлений.
- Два логотипа, доступных для скачивания из раздела «Материалы бренда» внизу сайта.
- Адаптация к телефонам, поддержка уменьшения анимации, локальные шрифты и изображения.

## Просмотр

Сайт находится в `dist`. Можно открыть `dist/index.html` в браузере или запустить из корня проекта:

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory dist
```

Затем открыть http://127.0.0.1:5173. Сайт не требует установки зависимостей или сборки. Для размещения на обычном статическом хостинге достаточно содержимого папки `dist`.

## Логотипы

- `dist/assets/syscore-horizontal.png`: 2172 × 724, прозрачный фон.
- `dist/assets/syscore-vertical-3d.png`: 1254 × 1254, белый фон.

Это растровые PNG. Для сайта также подготовлены облегчённые WebP-копии. Исходных векторных файлов нет.

## Контент и контакты

Сайт подготовлен по проектному документу от 02.06.2026. Планируемые услуги и образовательное сотрудничество не представлены как уже действующие. Финансовые прогнозы, внутренние поручения и неподтверждённые достижения не опубликованы.

В исходных материалах отсутствовали телефон, email, адрес и БИН. Поэтому раздел контактов сообщает о подготовке проекта к запуску. Формы отправки и сбора персональных данных нет. Когда появятся подтверждённые контакты, их нужно добавить в секцию `contact` файла `dist/index.html`.
